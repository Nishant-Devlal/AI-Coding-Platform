# AI Coding Platform

In this project, I am developing a LeetCode-style coding platform with an AI assistant
that provides contextual hints and guidance without directly revealing solutions.  
Right now it supports 2 languages to code in i.e C++ and Python. Will add more in future.

# Tech Stack
1. Frontend: Next.js and Typescript
2. Styling: TailwindCSS
3. Backend: FastAPI and Python
4. Database: PostgreSQL
5. Authentication: JWT
6. Cache: Redis
7. Code Editor: Monaco
